

# 开源框架

| 框架       | 主要贡献                                                           | 链接                                                                                                                                       |
| -------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| FAST_LIO | 提出基于迭代扩展卡尔曼滤波的高效 LiDAR-IMU 紧耦合里程计，实现高速、低延迟的实时 3D 状态估计与建图。      | [paper](https://arxiv.org/abs/2107.06829)<br>[github](https://github.com/hku-mars/fast_lio)                                              |
| GLIM     | 提出面向大规模 3D LiDAR-Inertial SLAM 的子地图与因子图框架，集成局部里程计、回环检测和全局地图优化。 | [homepage](https://koide3.github.io/glim/)<br>[paper](https://arxiv.org/abs/2407.10344)<br>[github](https://github.com/koide3/glim)      |
| mola     | 提供模块化、可扩展的现代 3D SLAM 框架，将里程计、关键帧地图、回环检测和因子图优化统一到一套工程化系统中。      | [homepage](https://docs.mola-slam.org/latest/)<br>[paper](https://arxiv.org/abs/2407.20465)<br>[github](https://github.com/MOLAorg/mola) |
